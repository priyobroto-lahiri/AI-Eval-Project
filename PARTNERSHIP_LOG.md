## Working Policy (Updated 2026-05-02)
1. **Autonomy:** Simple/single commands can be executed autonomously.
2. **Approval Gates:** Complex implementations or series of commands require explicit user "go ahead".
3. **Incremental Git:** We will follow a "Commit Early, Push Often" approach. Repo structure and docs must be pushed before implementation code.
4. **Session Context:** Once a command is approved for a session, it is considered pre-approved for the remainder of that session.
4. **Transparency:** The log is maintained in the project root for full visibility.
5. **Socratic Scaffolding (Learning Protocol):** 
    - **Concept:** Define logic and "Why" in plain English first.
    - **Structure:** Agent provides a code skeleton with `# TODO` blocks.
    - **Builder:** User implements the logic; Agent provides hints only.
    - **The Grill:** Agent asks critical "Senior Engineer" questions to verify deep understanding.
